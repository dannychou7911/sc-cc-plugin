# code review 準則

此內容為程式碼審閱原則。以通用原則加上特定語言準則進行審閱。

## 通用原則

1. 命名規則
2. 函數設計
3. 註解
4. 檔案結構化
5. 錯誤處理
6. SOLID 原則
7. 格式化與排版
	- 避免巢狀太深難以閱讀，最多兩層巢狀。
8. 測試
9. 程式碼風格


## JavaScript/TypeScript

1. 以 Airbnb JavaScript Style Guide 為主要依據。若團隊有規範則以團隊規範為準。
2. 迴圈以高階函數為主，例如map(), some()等。
