使用 GitLab MCP 取得專案 `$1` 的 Merge Request `$2` 的所有審閱回饋（Review Comments、Discussions、Suggestions）。

執行以下流程：

## 1. 理解審閱內容

- 逐一閱讀所有審閱意見。
- 將每則意見整理為：
  - 問題描述
  - 審閱者關注點
  - 建議修改內容
  - 涉及檔案與程式碼位置

## 2. 分析影響範圍

- 確認每項建議實際影響的程式碼範圍。
- 分析是否會影響：功能行為、商業邏輯、UI/UX、API 介面、狀態管理、共用元件、測試案例、型別定義、效能、可維護性。
- 標示是否可能產生連鎖修改。

## 3. 評估修正合宜性

- 判斷審閱意見是否合理，說明接受或不接受的理由。
- 從以下角度評估：Correctness、Readability、Maintainability、Performance、Consistency、Architecture、Team Convention。
- 若存在更佳方案，提出替代建議。

## 4. 提出修正方案

- 提供具體修改策略、預計修改的檔案、修改步驟、可能風險，以及必要的程式碼範例。

## 5. 產出最終報告

請使用以下格式輸出，**逐項審閱意見以表格呈現**：
